# 🧑‍💻 Website Portofolio Rahmateka

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Status: Online](https://img.shields.io/badge/Status-Online-green.svg)]()

Website portofolio pribadi **Rahmateka**. Platform ini digunakan untuk memperkenalkan diri, menampilkan proyek-proyek yang telah dikerjakan, dan membagikan informasi kontak profesional.

---

## 🌟 Fitur Utama

* **Halaman Tentang Saya (About Me):** Profil singkat, minat, dan *skill* teknis.
* **Bagian Proyek (Projects):** Daftar proyek yang telah diselesaikan, dengan deskripsi singkat dan tautan ke repositori GitHub atau demo.
* **Informasi Kontak:** Cara menghubungi Rahmateka (email, media sosial, dll.).
* **Desain Minimalis:** Fokus pada kemudahan navigasi dan penyampaian informasi yang jelas.

---

## 🛠️ Teknologi yang Digunakan

Website personal ini dibangun menggunakan teknologi *frontend* standar untuk memastikan kecepatan dan kompatibilitas:

| Kategori | Bahasa / Teknologi | Deskripsi |
| :--- | :--- | :--- |
| **Markup** | **HTML5** | Struktur konten utama (tentang saya, proyek, kontak). |
| **Styling** | **CSS3 / Framework CSS** | Penataan desain. (Misalnya, bisa menggunakan **Bootstrap** atau **Tailwind CSS** untuk mempercepat pengembangan). |
| **Logika (Opsional)** | **JavaScript (Vanilla JS)** | Untuk elemen interaktif kecil seperti menu navigasi responsif atau animasi sederhana. |
| **Hosting** | **GitHub Pages** | Platform ideal untuk menghosting website portofolio statis. |
| **Platform Awal** | **xo.je (untuk referensi)** | Website asli dibuat menggunakan platform website builder xo.je. |

---

## 💻 Instalasi dan Penggunaan (Jika Dibuat Manual)

Anda dapat mengkloning dan menjalankan proyek ini secara lokal:

1.  **Kloning Repositori:**
    ```bash
    git clone [https://github.com/rahmateka/rahmateka-portfolio.git](https://github.com/rahmateka/rahmateka-portfolio.git)
    ```
2.  **Masuk ke Direktori Proyek:**
    ```bash
    cd rahmateka-portfolio
    ```
3.  **Buka di Browser:**
    Cukup buka berkas `index.html` di browser Anda untuk melihat portofolio.

## 🌎 Bahasa yang Digunakan

Jika Anda membuat ulang website ini sebagai proyek statis untuk GitHub, bahasa dan teknologi yang digunakan adalah:

1.  **HTML5:** Untuk struktur dan konten dasar portofolio.
2.  **CSS3:** Untuk penataan gaya visual.
3.  **JavaScript:** Untuk interaksi dasar (misalnya, membuat menu burger responsif berfungsi).
4.  **Markdown (.md):** Digunakan untuk mendokumentasikan proyek dalam berkas `README.md`.

*Catatan: Platform `xo.je` sendiri menggunakan teknologi server-side (mungkin PHP, Python, dll.) di belakang layar untuk menjalankan layanan pembuat websitenya, tetapi kode yang di-generate dan didokumentasikan di GitHub adalah HTML, CSS, dan JavaScript.*
