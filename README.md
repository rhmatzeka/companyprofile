# Rahmat Eka: Early Portfolio

My first personal portfolio website: a simple one-page site that introduces me, lists my skills and achievements, and links to my social accounts.

> This is an older version. My current portfolio lives at [rahmateka.my.id](https://rahmateka.my.id).

## What's on the page

- **Home**: a short "Hello, I'm Rahmat Eka" intro
- **About me** and **achievements**
- **Skills**
- **Let's connect**: links to GitHub, LinkedIn, Instagram, X, and WhatsApp

## Tech stack

HTML and CSS, with Font Awesome icons and the Roboto font.

## Run it

Open `index.html` in your browser.
